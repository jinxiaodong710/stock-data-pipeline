
## NAS 电源故障（晓东的野群晖）
- 现象：野群晖（黑群晖）NAS 点不亮，怀疑电源坏
- 机器：**单盘**（Basic，非 RAID/SHR）
- 电源铭牌（晓东拍照）：**益衡/Enhance ENP-7025 系列**
  - 型号 ENP-70258 / ENP-70259
  - **1U Flex 规格**，**250W**，80PLUS 铜牌
  - 输出：+3.3V/13A、+5V/14A、+12V1/18A、+12V2/18A、-12V/0.3A、+5Vsb/2A
  - 输入 100-240V~ 3.5-1.5A 50/60Hz
  - ⚠️ 铭牌有 "SELECT THE RIGHT VOLTAGE / 危险区" 警告 → 可能带 115/230V 手动切换开关，国内须打 230V
- 建议：买同款 **ENP-7025B**（淘宝 60~120 元）；注意尺寸(1U Flex 150×81×40.5mm) + SATA 口数量
- 数据：单盘数据在盘上，可插回黑群晖(选迁移/别初始化)、或硬盘盒+Linux(mdadm)、或 Windows 用 DiskGenius(仅 ext4；btrfs 需 Linux)
- 待办：确认硬盘数量、是否要另买新 NAS
