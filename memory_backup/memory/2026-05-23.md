## 🧠 上下文机制学习

晓东详细讲解了上下文怎么传给模型，纠正了我之前的错误理解。

**关键认知纠正：** 不是「所有历史对话全文无脑打包」传给模型，而是「按需重组拼装」。

### 分层结构
| 层级 | 策略 |
|------|------|
| 系统提示 | ✅ 最稳定，几乎必带 |
| 当前会话消息 | ✅ 相关消息带上，太长则压缩 |
| 工具调用结果 | ⚠️ 太长截断，只保留关键部分 |
| 持久记忆 | ✅ 提炼后的长期事实，不是全文 |
| 技能（skill） | 🔸 按需加载，不是全部默认塞 |
| 历史会话 | 🔸 档案库，按需检索，不默认全带 |

### 什么时候会丢内容？
- 上下文太长 → 系统自动压缩成摘要（HEARTBEAT里的手动截断不需要了）
- 工具输出太长 → 截断/分页/摘要
- 话题切换多轮 → 旧话题弱化
