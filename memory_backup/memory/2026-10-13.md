
## 2026-10-13 头等舱浮点 bug 修复（晓东发现）
- **现象**：晓东问「300715为什么不可以」——凯伦股份 10-13 +13.45%（收15.52，收盘=最高，光头阳线）被头等舱漏掉
- **根因**：第3关「上影线比例」浮点误差
  - 公式 ratio = pct_change / high_pct_change
  - close==high 时理论应为 1.000，但分子 pct_change 用 Redis 昨收(13.68)、分母 high_pct_change 用 DuckDB float32 昨收(13.6800003)
  - 算出 1.0000002，刚好越过 between(0.79, 1.00) 上限 → 被误杀
- **修复**：`df["close_to_high_ratio"] = df["close_to_high_ratio"].round(6)`
  - Mac `~/go/head_class_selector.py` 已改；首尔(ubuntu@43.155.197.236) 已同步，旧文件备份为 `.bak_20261013`
- **验证**：修后重跑 → 选出 1 只：300715 凯伦股份，持股3天，止损14.74
- **教训**：凡「收盘=最高」的光头阳线强势票，都可能被此浮点误差误杀（长期存在）
- **待办**：16:15 自动采集任务 `com.stock.daily-collect` 自 10/5 起失效（launchd 未 load），现只剩凌晨 1:15 的 `com.mia.stock-collect`（采上一交易日）→ 10-13 数据是手动补采的。已问晓东是否修。
