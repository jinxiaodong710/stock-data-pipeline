
## 每日早报 cron 修复（OpenClaw 升级后遗症）
- 症状：`每日新闻早报` job 报 `Automation has no recorded inference account. Explicitly select its account with a model@profile update before running it.`
- 根因：升级 2026.11.1 后，旧 cron job 的 model 是裸 `deepseek/deepseek-flash`（无 @profile），丢失推理账户绑定
- 修复（必须走 CLI operator 路径，agent 工具 update 会因 owner session 不匹配报 `scheduled account policy must match the persisted job owner`）：
  `openclaw cron edit <id> --model 'deepseek/deepseek-flash@deepseek:default' --tools 'web_fetch,exec,write,read'`
- profile 名 `deepseek:default` 见 ~/.openclaw/openclaw.json 的 auth.profiles
- 验证：`openclaw cron run <id>` 手动触发，run status ok / delivered
- 命令是 `openclaw cron ...`（不是 `openclaw automations ...`，automations 只是 agent 工具名）
