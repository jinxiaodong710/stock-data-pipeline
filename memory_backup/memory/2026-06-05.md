## 数据采集大修
- scorer 总是用 6/1 数据 → 根因：6/2~6/5 采集连续失败
- NAS 原程序是全删全采（`DELETE FROM stock_prices`），本地版被人改成了增量（`WHERE date = ?`），日期格式不匹配（YYYYMMDD vs YYYY-MM-DD），导致 DELETE 空跑、INSERT 重复键
- 晓东 NAS 上的 `stock_data_collector.py`（`192.168.3.40/新建文件夹/`）是正确的全删全采版本
- 教训：用晓东已有程序，不要自己改代码
