
## 2026-07-31 重要事件

### 1. 微信通道静默故障（7/30-7/31）
- 现象：所有 cron 主动推送微信全部失败 `sendMessage ret=-2 errmsg=prepare failed`，持续两天，晓东两天没收到消息
- 根因：微信插件 outbound 链路 contextToken 失效
- 修复：gateway 重启（SIGUSR1）→ 插件重新初始化 → 恢复
- 教训：cron 失败告警本身也走微信通道，所以静默故障无法自愈发现。**已加「米娅心跳自检」cron（每天9:00/21:00发测试消息，连败2次告警）**
- 晓东批评点：「你不要再把问题推到微信通道」——即使通道故障，也是我的监控缺失
