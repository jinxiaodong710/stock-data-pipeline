- 备份：`~/backups/openclaw-preupgrade-20261020-0817.tar.gz`

### 踩到的 5 个坑（Mac 升级必看）
1. **新版要求 Node ≥24.16 <25 或 ≥26.1.0**（毛毛原 22.20 装不上）
2. **npm 11 默认禁止 install scripts** → 必须 `npm i -g --allow-scripts=@google/genai,esbuild,koffi,protobufjs,openclaw ...`
3. 旧配置废弃键会让启动直接拒：`gateway.tailscale.resetOnExit`、`meta.lastTouchedAt`、`gateway.controlUi.allowInsecureAuth`、`agents.defaults.models`、provider `compat` 覆盖
4. agent DB schema v1 需 `openclaw doctor --fix`，且**要跑两遍**（第一遍报 Plugin migration source config changed）
5. 插件要跟着升：`openclaw plugins update @tencent-weixin/openclaw-weixin@latest`（2.4.3 → 2.4.10）

### Mac Node 升级（v26.0.0 → v26.12.0）
- ❌ `brew upgrade node` 出事故：brew 升级 ada-url 后删了 `libada.3.dylib`，旧 node 26.0.0 直接 dyld 崩溃，gateway 重启失败一次
- ✅ 改用官方二进制：解压到 `/opt/homebrew/lib/nodejs/node-v26.12.0-darwin-arm64`，`/opt/homebrew/bin/node` 和 `/opt/homebrew/opt/node` 都指向它，npm 换官方版并设 `prefix=/opt/homebrew`
- 教训：**Homebrew 升级大版本 node 有依赖断裂风险，官方 tarball 更可控**

### Gateway 交接
- node 事故后 gateway 从 shell 脱离成「野生进程」（不受 launchd 管），launchd 反复拉新实例都因端口占用失败
- 第一次交接脚本失败：**用了 setsid，macOS 没有这个命令**
- 第二次失败：`pgrep -f "openclaw/dist/index.js gateway"` 匹配不到（进程 argv[0] 是 `openclaw`）
- ✅ 第三次成功：**按端口占用者 PID 精确 kill** → `lsof -nP -tiTCP:18789 -sTCP:LISTEN | xargs kill`
- 现在：PID 96069，launchd 托管，KeepAlive，Node 26.12.0，OpenClaw 2026.6.6
